# Security policy

BARQ-CRS accepts reports for defects in its parsers, scope enforcement, evidence
handling, and local analysis engines. Please avoid publishing a working bypass
before a fix is available.

## Supported version

The latest minor release is supported.

## Reporting

Open a private security advisory in this repository. Include the affected
version, minimal reproduction, expected behavior, and impact. Remove tokens,
cookies, personal data, and third-party target data.

## Research boundary

Use BARQ-CRS only on assets you own, isolated competitions, or targets for which
you have explicit written permission. A program's scope and rules override any
example in this repository. The project intentionally does not provide an
unattended live-target executor.
